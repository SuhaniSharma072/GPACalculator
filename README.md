This GPA calculator is an application designed to output the user's weighted GPA (inclusive of any weighted classes they take such as Honors or Advanced Placement).
It firsts asks users how many classes they're taking to know how many times it should repeat a segment of the code in a loop. Then it asks if user is taking any AP or Honors classes and if so, the weight for each.
It then asks for the user's grade in a class along with what kind of class it is ( On level, AP, Honors) and repeats it for how many ever classes there are. Then it outputs the weighted GPA.
